# SeriousiOS

An open-source iOS porting project for **Serious Sam Classic: The First Encounter** and **The Second Encounter**, based on Serious Engine 1.10.

## Project status

Early architecture and build-system bootstrap. The immediate goal is a reproducible arm64 iOS build with statically registered game modules, followed by a native touch and gyroscope control layer derived from the proven eDukeiOS interaction model.

## Game data

This repository does **not** contain Croteam's copyrighted game assets. Users must provide legally owned original game data (`.gro` files).
